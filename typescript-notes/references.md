# TypeScript References & Learning Resources / Tài Liệu Tham Khảo Hay

## 📘 Tài Liệu Chính Thức / Official Documentation

- **[TypeScript Official Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)** — Tài liệu chính thức từ cơ bản đến nâng cao của Microsoft.
- **[TSConfig Reference](https://www.typescriptlang.org/tsconfig)** — Tra cứu chi tiết toàn bộ các cờ cấu hình trong `tsconfig.json`.
- **[TypeScript Playground](https://www.typescriptlang.org/play)** — Môi trường thử nghiệm kiểu dữ liệu và xem kết quả biên dịch JS trực tiếp trên trình duyệt.
- **[TypeScript Performance Wiki](https://github.com/microsoft/TypeScript/wiki/Performance)** — Hướng dẫn tối ưu tốc độ biên dịch và viết kiểu hiệu quả từ đội ngũ phát triển TypeScript.

---

## 🧠 Luyện Tập & Thử Thách Về Kiểu / Type Challenges & Interactive Practice

- **[Type Challenges (type-challenges)](https://github.com/type-challenges/type-challenges)** — Bộ bài tập luyện viết Utility Types từ Easy -> Medium -> Hard -> Extreme (cực kỳ hữu ích cho phỏng vấn Middle/Senior).
- **[Total TypeScript (Matt Pocock)](https://www.totaltypescript.com/tutorials)** — Các bài hướng dẫn thực tế về Generics, Type Transformations và Zod.
- **[Execute Program - TypeScript](https://www.executeprogram.com/)** — Học TypeScript qua các bài tập tương tác ngắn.

---

## 📚 Sách & Hướng Dẫn Chuyên Sâu / Books & Deep Dives

- **[Effective TypeScript (Dan Vanderkam)](https://effectivetypescript.com/)** — Cuốn sách gối đầu giường với 62–83 quy tắc viết TypeScript thực chiến.
- **[TypeScript Deep Dive (Basarat Ali Syed)](https://basarat.gitbook.io/typescript/)** — Sách miễn phí trực tuyến giải thích rõ cơ chế hoạt động bên dưới của TypeScript.
- **[Google TypeScript Style Guide](https://google.github.io/styleguide/tsguide.html)** — Quy chuẩn viết code và đặt tên TypeScript chuẩn doanh nghiệp của Google.

---

## 🛠️ Công Cụ Hệ Sinh Thái Đáng Chú Ý / Essential Ecosystem Tools

- **[typescript-eslint](https://typescript-eslint.io/)** — Bộ quy tắc lint phát hiện lỗi tiềm ẩn (như `@typescript-eslint/no-floating-promises`, `@typescript-eslint/no-explicit-any`).
- **[Zod](https://zod.dev/)** — Thư viện kiểm tra dữ liệu lúc runtime kết hợp suy luận kiểu TypeScript tự động (`z.infer<typeof Schema>`).
- **[ts-reset](https://github.com/total-typescript/ts-reset)** — Cải thiện các kiểu mặc định chưa an toàn của TypeScript (như biến `JSON.parse` và `res.json()` trả về `unknown` thay vì `any`).
